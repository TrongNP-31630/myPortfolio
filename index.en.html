Pikachu Classic

04 — 07 / 2026

Game engine · Pathfinding & matrix shuffling

A Java tile-matching game developed by a team of five. I designed and implemented two algorithms: BFS pathfinding with at most two turns, and shuffling remaining tiles when no valid move is available.

  • Java 17
  • BFS
  • 2D arrays
  • Queue / LinkedList
  • Collections.shuffle
  • Swing · Graphics2D

MY CONTRIBUTIONS · ALGORITHMS

  • BFS pathfinding: search a 2D grid while tracking direction and turn count; find a valid connection with at most two turns, preferring fewer turns.
  • Matrix shuffling: collect remaining tiles, shuffle them, and redistribute them among occupied cells; preserve empty cells and check for valid matches.
Algorithm design details +

1. Pathfinding — findPath()

Each state stores a row, column, direction, turn count, and parent node. A Queue/LinkedList explores four directions, allowing movement through empty cells or the destination and rejecting states with more than two turns.

The minTurns[row][col][direction] array stores the best turn count for each cell and incoming direction, pruning states that do not improve the result. At the destination, the algorithm prefers fewer turns and follows parent nodes to reconstruct the coordinates.

2. Board shuffling — swapMatrix()

Collect IDs from remaining tiles into an ArrayList, call Collections.shuffle(), and redistribute them among occupied cells. This preserves the count of each tile type and all empty positions.

After shuffling, checkValidMatrix() searches for matching IDs and calls findPath() to check connectivity. If no connectable pair exists, it shuffles again.

How the algorithms work togetherBFS validates connections; the shuffle algorithm uses that result to validate the new board.
